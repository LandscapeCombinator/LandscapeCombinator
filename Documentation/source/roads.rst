Roads From Splines
====================

The ``RoadsFromSplines`` actor generates road meshes from spline components. It's
used together with the :ref:`SplineImporter <splines>` to automatically create road meshes
from OSM road data.

To use it, drag a ``RoadsFromSplines`` actor into your level, select the spline components
to use (or leave it set to all splines), configure the road parameters, and click
``Generate Roads``.
